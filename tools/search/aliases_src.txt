# Line format:   phrase, phrase, ... => target, target, ... // note shown under the first result // hint: line shown above the results // near: target // src: source ids
#   target = mol:<id> crystal:<id> el:<Symbol> node:<id> (or just the node id) kn:<id> lm:<Landmark label> pl:<Name> trail:<id> lab:<lab>/<preset>
#   targets are listed best first; the first is shown first.
#   near: marks a target that is only the NEAREST thing the explorer has (the result then says "Nearest model we have").
#   every line needs src: (ids from the @src lines below). Phrases are matched after lower-casing, dropping accents, punctuation, plurals
#   and filler words (a, the, what is, how does ... work), so "whats water made of" and "water" are the same phrase.
# Rule: an alias must be TRUE. A common name goes to the thing it really is; if the explorer only has a near relative, say so with near:.
