# Figure report: bio_b (biology, second half)

File: `data/viz/bio_b.json`, generated by `tools/viz/gen_bio_b/gen.py` (parts p1 to p6, shared helpers in lib.py; `view.sh` and `shot.py` render batches).

Coverage: 210 of 210 target nodes (every node in the seven bio_* area files not already in another viz file). Validator: 210 specs, 0 errors. Headless render of all batches: no VIZ_ERRORS.

Counts by type: plot 94, blocks 79, bars 18, geometry 12, dist 4, parametric 1, heatmap 1, graph 1. 109 figures have sliders; all have captions.

Highlights: allele-frequency selection and drift, Fst, molecular clock, Kleiber scaling, Hill oxygen curves, action potential and EPSP summation, logistic and Lotka-Volterra, SIR phase relation, species-area, power and CI coverage simulations, Beer-Lambert, Abbe limit, PK decay, ROC curve, bistable ecosystem tipping, flow-cytometry gating heatmap.

Weak spots:
- Lotka-Volterra uses the small-amplitude (linearised) solution, not the full nonlinear cycle; the caption says so.
- SIR is shown as the exact i(s) phase relation, not a time series (expressions cannot integrate ODEs).
- Several curves are schematic (auxin dose, Lenski fitness, two-process sleep model, energy-system shares, Allee, ecosystem tipping); captions mark them as schematic or approximate.
- Gamma functions (t, chi-square, gamma, CLT) use a Stirling approximation, accurate to a few percent at df >= 2.
- Phylogenies are simplified to depth <= 4 as boxes so labels fit; they omit many clades.
- Process nodes use single-column chains (long step titles); loop return edges (Krebs, Calvin) are drawn but are subtle.
- Species counts, genome sizes and extinction percentages are approximate round figures.
- Blocks labels were linted for overlap at 312 px width; wider cards will have more room.
